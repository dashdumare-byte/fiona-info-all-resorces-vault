---

## Step 0: Universal Research (NEW)

**Before ANY code generation:**

1. Module assignment announced to all 8 models
2. ALL 8 models perform independent research (parallel, 30-60min)
3. ALL 8 models cross-verify each other's findings
4. FacTool verifies factual claims
5. AEGIS-99 Research Consensus >=0.90
6. If PASS -> compile MASTER BRIEF
7. If FAIL -> redo research, notify Ashandy

**Cost**: ~$1.50 (standard) / ~$3.90 (critical) per module
**Time**: 60-115 minutes per module

---

## Step 1: Pre-Module Research

- Kimi K2.7 Agent mode + DeepResearcher
- Now informed by MASTER BRIEF from Step 0
- Module-specific deep dive
- Cost: ~$0.15 per module

---

## Step 2: Proof Discovery

- Axplorer fires (mandatory for Module 68)
- Mathematical pattern discovery before code
- Reduces Leanstral proof burden
- Cost: Near-zero

---

## Step 3: Parallel Code Generation

- Critical modules: L3 Premium pool
- Standard modules: L2 Standard pool
- Each model uses its OWN research + MASTER BRIEF
- Each model references its research in code comments
- Cost: ~$2-5 per module

---

## Step 4: AEGIS-99 Consensus

- All outputs scored by weighted consensus
- Threshold: >=0.85 standard / >=0.90 critical / >=0.95 Module 68
- If FAIL -> activate [[F-GARP - Deadlock Recovery]]
- Cost: Near-zero (AEGIS models already engaged)

---

## Step 5: Formal Verification

- Leanstral proof generation (if math involved)
- DeepSeek-Prover-V2 parallel proof
- Module 68: ALL tolerance math formally verified
- Cost: ~$0.20-0.50 per proof

---

## Step 6: [Reserved]

- Tier 1 review triggers here (4-hour cycle)
- Gemma 4 + GitNexus + super-smoke-test + NeMo Guardrails + Pylint
- Does NOT block progression — runs in parallel

---

## Step 7: 3-Supervisor Review

1. Claude Code review (production, security, visual)
2. Codex review (adversarial, AEGIS validation, cross-check)
3. OpenCode review (independent, alternative impl, Lean4)
- All 3 must PASS
- Cost: ~$0.50-1.50 per module

---

## Step 8: Cursor Hard Gate

See [[Cursor Hard Gate]] for all 12 checks.

**ZERO TOLERANCE**: Any check fails = module does NOT ship.

---

## Post-Gate

### PASS
- Module committed to git
- State updated in Supabase
- AEGIS score logged
- Proceed to next module

### FAIL
- Error pattern logged to lessons.md
- Module returns to appropriate step
- Retry count incremented
- If retry >= 5 -> overseers activate diagnostic
